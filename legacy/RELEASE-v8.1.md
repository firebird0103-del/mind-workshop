# v8.1 入口比例修訂

依使用者提供的實際比例圖修訂，保留 v8 版本。

- 桌面入口五個主要區塊統一 width:min(1360px,71vw)，不再只用固定 max-width。在 1920 CSS px 下內容 1360px，左右各 280px；1440 下內容約 1022px，左右各 209px。
- 1199px 以下改用可用寬度，820px 以下維持單欄，避免縮窄後影響閱讀。
- 主標／關卡／品牌字重由 500 改 600；說明保留 400，重建層次但不採 800/900 厚黑。
- 紙膠帶加小撕邊與淡層次；紙卡邊框與折角修整。
- 修正舊設計系統以 !important 蓋過「開始」膠囊圓角的問題。
- 記憶小插圖僅在入口以 multiply 混色融合白底；不是修改原始圖集，彩色區域會略受紙色影響。
- 雲雲貼紙、四關玩法、形色預設 10 題、音效與紀錄功能未改。

驗證：game-logic.cjs、v6-layout-names.cjs、v7.cjs、v8.cjs 通過。新增 1200/1280/1366/1440/1600/1920 六種 CSS 邏輯寬度的比例契約測試。此非實際瀏覽器量測。

目前沒有完成實際瀏覽器截圖驗收，先前存取限制未繞過。請以 index.html、100% 瀏覽器縮放，在實機全螢幕確認留白、文字、紙卡、記憶縮圖；若仍有差異，請附截圖及瀏覽器縮放比例。
