# 心智大作戰｜v10.7 紀錄匯出與匯入

「遊玩紀錄」視窗新增「匯出資料」與「匯入備份」。匯出一份 ZIP，內含五張工作表的研究用 Excel、完整 JSON 備份及使用說明。匯入可選擇合併或取代，並預覽筆數與略過重複紀錄；清空後仍可開啟視窗還原。

**接續既有紀錄：**將本資料夾內的檔案覆蓋到原遊戲資料夾，維持原入口網址／檔案路徑，使用原本瀏覽器及使用者設定檔。資料仍保存在瀏覽器，換到新路徑或另一個瀏覽器可能看不到原紀錄。更新後可先匯出一份備份，再進行搬移。

**一般使用：**完整解壓縮後開啟 `index.html`。匯出及匯入都在本機完成，不需要網路。

完整操作、統計定義、資料限制及驗證範圍見 [RELEASE-v10.7.md](RELEASE-v10.7.md)。截圖與檢查摘要在 `preview/v10.7/`。本版保留 v10.6 已確認的第三關觀看高度。

# 心智大作戰｜v6 百件素材與螢幕適配測試版

以下是原 Phase 2 的歷史設計紀錄；新版差異與實測限制以 RELEASE-v6.md 為準。

## 定版狀態
本版本為 2026 展覽用 Phase 2 Final，基於使用者確認過的 Phase 2 Step 14（以 Step 13C 為基準重整 Top 5）再完成最終平台收尾。

### 四款正式遊戲
1. 空間認知｜視空間／時間理解
2. 找錯｜視覺注意力
3. 工作記憶｜短期／工作記憶
4. 語意判斷｜執行功能／認知彈性／反應抑制

### 已定稿的互動原則
- Touch First
- Responsive
- 長者友善
- 玩家年齡不直接改變遊戲難度
- 遊戲玩法與 Core 分離
- 既有 Phase 1 視覺與三款遊戲玩法視為定稿

### 第三關定稿節奏
- 3 / 2 / 1 / GO：總計 4 秒
- 每張圖片：1.2 秒
- 圖片間隔：0.3 秒

### 第四關定稿節奏
- 開始後直接進第一題
- 無 3 / 2 / 1 / GO
- 點完立即進下一題
- 無「下一題」按鈕

### 英雄榜
- 顯示 Top 5
- 同一玩家不同次成績可以同時上榜

## Phase 2 平台能力
- Game Module / Plugin API
- Game Module Lifecycle
- Dynamic Game Launcher
- Game Config Layer
- Config Runtime API
- Config Admin UI
- Config Preset / Game Mode
- Asset Manager
- Audio Manager
- Shared Feedback Manager
- Platform Preflight

## 管理工具
- `config.html`：圖形化 Config 後台，可調整遊戲參數。
- `platform-check.html`：發佈前平台自檢。

## 建議啟動方式
展覽現場直接開啟 `index.html`。

管理參數時開啟 `config.html`。
部署前可開啟 `platform-check.html` 確認平台服務與四款內建遊戲均通過。

## Phase 2 Final 原則
本版本進入定版後，不再加入新的核心功能。後續新增統計、內容編輯器、更多遊戲等工作，移至下一階段 Phase 3。
