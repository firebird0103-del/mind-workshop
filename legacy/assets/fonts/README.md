# 入口圓體

`jf-openhuninn-2.1.ttf` 為 justfont 官方釋出的 jf open 粉圓 2.1 原始檔，未修改字形、字體名稱或內容。

來源：https://github.com/justfont/open-huninn-font/tree/master/font

授權與著作權資訊：`OFL.txt`。字體隨專案附上以支援離線入口；只有 `brain-playground.css` 使用此字體。

## v10.1 中等字重

`GenSenRounded2TW-M.woff` 取自源泉圓體月 2.100 的 Medium 原檔 `GenSenRounded2TW-M.otf`，原生字重為 500。使用 FontTools 轉換為 WOFF 網頁字體格式，保留完整字集與字形，未子集化或改造字形。

來源：https://github.com/ButTaiwan/gensen-font/tree/master/otf/TW

授權與著作權資訊：`GenSen-OFL.txt`。此字體用於入口標題、關卡名稱、編號與主要操作文字；說明與年齡選項仍使用原有一般字重。
