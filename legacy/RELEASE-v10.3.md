- 保留 h1 / h2 的文字內容供輔助工具辨識；裝飾圖不重複朗讀。

## 實作與維護

`brain-title-art.css` 只處理入口標題；入口引入兩份本地圖稿：

- `assets/playground-title.svg`
- `assets/brain-brand-title.svg`

兩份 SVG 是透明 PNG 圖稿的自包含顯示容器，使用 viewBox 排除多餘透明留白；內含的是點陣圖稿，並非文字轉曲的向量路徑。原圖像素未經程式改畫；不依賴外部網站或額外安裝字型。若日後更名，需同步更新標題圖稿和 HTML 文字。

圖稿由內建 image_gen 依確認示意製作，相關提示與用途記錄在 `assets/TITLE-ART.md`。

四關 HTML、所有既有 JavaScript、遊戲參數、素材、既有 CSS 均保留。入口的內嵌 JavaScript 亦保持原樣。舊版 README 與發佈紀錄保留作歷史資料。
