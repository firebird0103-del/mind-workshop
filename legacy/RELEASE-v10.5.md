# v10.5｜第二關雙圖對齊

## 問題與修正

v10.4 將第二關上方功能列對齊最大 1920px 的外框，但內部雙圖區受可用高度限制，實際寬度較小，造成上方兩側仍突出。

本版只調整 `brain-game-frame.css` 中第二關的規則：

- 功能列、說明列、左右雙圖外緣與下方操作列共用同一寬度。
- 桌面外框依視窗高度設定適合雙圖的寬度上限：`clamp(720px, calc(200svh - 620px), 1480px)`，同時不超過可用螢幕寬度。
- 固定視窗下，4×4、5×5、6×6 維持相同外框寬度。格子數增加時在既有圖板範圍內分配，不讓外框隨題目跳動。
- 640px 以下改為上下圖板，外框上限與單圖區一致為 480px，再隨可用寬度縮小。
- 維持原有格子最小尺寸及圖板內捲動；較窄或較矮的螢幕允許必要的捲動，不壓縮觸控格子。

例：1911×931 視窗的功能列與雙圖均為 1242px；1366×768 視窗均為 916px。第一、三、四關樣式規則、所有 JavaScript、題數、判分與入口標題皆保留 v10.4。

## 驗證

以 Microsoft Edge 155（Chromium）直接開啟本地 `file://` 頁面，在 13 種視窗尺寸各完成第二關三題，共 39 個遊玩配置；另檢查各題回饋與結果階段。

檢查：上方功能列、主面板、說明列、雙圖區與操作列左右邊界誤差小於 1px；準備到三題及結果外框寬度穩定；頁面無水平溢出；答案格尺寸至少 44px；無 JavaScript 執行錯誤。

視窗包括：1920×1080、1911×931、1440×900、1366×768、1024×768、844×390、768×1024、641×800、640×800、600×800、390×844、320×740、3840×1860。

`preview/v10.5/` 提供 1911px、1366px、390px 寬度下的三題實際截圖及 `verification.json`。本版未另行啟動 Electron。其他 preview 檔案屬於先前版本紀錄。
