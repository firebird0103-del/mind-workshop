# v10｜暖色腦力遊樂場入口

依 2026/10/09 確認的示意修訂入口。完整解壓縮 ZIP 後，開啟 `index.html`；JS、CSS 與 `assets/` 必須保留在原有相對位置。入口字體與圖片均隨版本附上，可離線載入。

## 入口配置

- 暖奶油色背景、淡淡的邊緣色塊，中央保留乾淨留白。
- 四關採同尺寸的奶白底板，文字、開始按鈕與裝置共用同一張底板；四個圓角線段帶出藍、珊瑚紅、黃、青綠的框感。
- 每座裝置後方加入對應的淡色有機色塊；移除原先的中央圓點與虛線連接。
- 四關統一文字在左、裝置在右，開始按鈕維持一致的位置。桌面與平板為 2×2，手機直向排列。
- 標題以簡化的暖橘色括弧呼應框線，保留較輕的粉圓字體與放大的原始雲雲 Logo。
- 年齡選項整合為完整的底部區塊，沿用奶白底板與分段圓角框；選取狀態改為暖橘色，並保留文字對比與 aria-pressed 狀態。
- 音效與遊玩紀錄使用同一個淡色圓角工具列，保留原有操作。
- 游標移入時淡淡提亮底板與框線，裝置微動；縮減動態設定會關閉動畫。
- 暱稱與紀錄視窗的底色、邊線同步改為暖色。

## 保留的遊戲內容

與 v9.2 比對，四關遊戲 HTML、遊戲 JS、Core、Config、02／03 的 100 件共用素材、Logo 原圖與第四關裝置 PNG 均未修改。02／03 入口裝置仍直接顯示同一份原始圖庫。年齡選擇、暱稱、成績與音效邏輯沿用原版。
