# v6｜100 件素材・螢幕適配・隨機暱稱

2026-10-02。以 v5 為基礎；原始 zip 與已交付的 v5 檔案保留。

## 四項要求

1. 素材補到 100 個
   - 新增 20 種：足球、網球拍、吉他、鼓、鉛筆、畫筆、尺、水壺、湯匙、叉子、牙刷、梳子、吹風機、襪子、手套、澆水壺、磁鐵、禮物盒、手電筒、電風扇。
   - 找錯與工作記憶都使用完整 100 件圖庫。
   - 預設找錯三題共需要 86 個物件位置，現在三題之間也不會重複。自訂較多題／較大盤面，在用完 100 件後仍可能跨題重用。

2. 減少捲頁
   - 記憶關的選項依剩餘寬高計算欄數與格子大小，不再固定把選項撐成四大排。
   - 補回答案區缺少的 answer-area 類別，使間距、排列與換行正常套用。
   - 送出後收起選項，把原區域切換成「你的排列」與「正確順序」；答案不再加到整片選項下方。
   - 下一題重新顯示選項，最終結果隱藏作答列；不變更展示時間與預設難度。
   - 時鐘依提示、結果和操作按鈕所占高度調整尺寸；語意判斷依剩餘寬高調整選項排列。
   - 遊戲大面板不再套用大廳卡片的滑鼠懸停上移效果。
   - 不用 overflow:hidden 硬藏內容。小手機、超短視窗、放大字體、極高密度自訂題仍可能需要捲動，保留操作尺寸與可讀性。

3. 第二關說明列過寬
   - 標題、規則與分數集中在較窄的橫式說明列。
   - 說明列與上方品牌列依雙圖的顯示寬度縮放，不再橫跨整個大螢幕。
   - 極短視窗時說明列保留最低合理寬度；窄螢幕允許換行，避免文字擠壓。

4. 隨機暱稱
   - 名字欄旁新增「隨機取名」，按下會填入名字；再按「換一個」可重新抽取。
   - 下面另外提供三個建議暱稱，可直接點選。
   - 共 400 組本機組合，不連網，也不是實名資料。
   - 開啟視窗不會蓋掉上次的名字；選完可手動修改，按開始才儲存。
   - 留白仍使用「訪客」。暱稱不是帳號，不保證跨裝置、跨玩家唯一。

## 開啟

完整解壓縮後開啟 index.html。請保留 assets、JS、CSS，勿只複製 HTML。
art-gallery.html 可查看全部 100 件素材與 48px 小尺寸。
assets/ARTWORK.md 保存五張圖集的路徑、製作方式與完整提示詞。

## 驗證

- 所有 JavaScript 與 HTML 內嵌腳本語法檢查；HTML 連結的本機資源存在。
- 找錯 144 組設定、432 題：差異數、盤面不重複、扣分、換題、防重複計分、最終紀錄。
- 記憶長度 3 / 5 / 6 / 8：展示、排列、取消、答案揭示、送出鎖定；驗證揭示時選項隱藏、下一題恢復。
- 100 件圖像均有內容；4950 組兩兩像素比較未發現重複。逐張檢視新增圖集並計算每件物件的裁切視窗；中性灰色餐具也納入圖像內容檢查。
- 400 組暱稱唯一性，2000 次重抽不連續相同；測試建議選取、手動改名、儲存與訪客流程。
- 42 組尺寸計算，時鐘出現結果時縮小以保留空間；語意判斷穩定尺寸下不重複寫入樣式。
- 修改的 CSS 括號配對檢查。

測試使用模擬 DOM、模擬時間與提供的寬高數值，不是瀏覽器排版引擎。未完成瀏覽器／全螢幕／實體觸控驗收；不宣稱所有裝置均完全免捲頁。

建議你優先試：
- 你提供截圖的全螢幕與縮放比例。
- 第三關「選項出現 → 送出 → 看答案 → 下一題」是否都不用捲頁。
- 第二關說明列的寬度是否合適。
- 打開名字視窗、選建議、換一個、再手改並開始。
