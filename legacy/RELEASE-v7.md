# v7：C1 入口、文字色彩干擾與音效

## 本版內容
- 入口依最後定案 C1：四色標誌、年齡列、四關細框；02 單一 2×2 並圈蘋果、03 小順序圖案、04 右側 2×2 圖形。小時鐘有雙指針。
- 保留 100 件原素材、隨機暱稱、各關玩法、計分、題數與紀錄格式。
- 形色關鍵字採當題錯誤選項的顏色，排除正確答案顏色；以深色同色系字體確保白底可讀。未新增練習、干擾說明或紀錄版本欄位。
- 修正形色原本以物件字串判斷重複、可能改壞正確圖形的處理。
- 音效開關在入口及各關均可使用，以本機儲存記住設定。加入找錯、記憶作答結果與四關完成音效；不加入背景音樂。
- 選項作答不再疊加通用按鈕音。記憶展示沒有聲音提示。
- 輕量卡片按壓、彈窗及結果動畫；尊重減少動態設定，不延遲形色換題或改變計時。
- 清除紀錄移到遊玩紀錄內，保留原確認程序。

## 驗證限制／請實機確認
以上為邏輯與靜態測試，不代表瀏覽器排版、實際拖曳、觸控或喇叭已測試。
請解壓後開啟 index.html，在全螢幕及一般視窗測試：
1. 年齡 → 隨機／手動暱稱 → 四關 → 結果 → 紀錄。
2. 形色兩種規則都依文字意思選答案，文字顏色指向其他選項。
3. 音效開關跨頁與重新開啟保持一致；實際音量是否舒服。
4. 1366×768、1920×1080 和窄螢幕檢查；小螢幕允許必要捲動，不能裁切操作區。
