# v10.6｜第三關觀看高度

## 調整

第三關進行倒數與圖片展示時，畫面焦點原本集中在螢幕上半部。本版依確認的示意圖加高右側黃色展示區，讓圖片中心下移，功能列、主面板頂部及左側說明維持原位。

- 在寬度至少 821px、高度至少 700px 的視窗，展示區最小高度為 `68svh`。圖片與上方序號作為同一組內容垂直排列。
- 倒數數字與圖片放在同一個格位，確保切換時觀看中心不偏移。
- 適用桌面尺寸的圖片仍為原本 320×320px；小螢幕仍沿用原有縮放規則，並限制圖片不超過容器寬度。
- 手機、單欄平板及矮螢幕不預留額外展示高度。
- 樣式只在 `data-phase="showing"` 生效，答題與回饋恢復既有排列。

新增 `brain-memory-stage.css`，由第三關 HTML 引入。所有 JavaScript、遊戲設定、原有 CSS、其他關卡 HTML 及入口圖稿保持原樣。倒數仍為 3／2／1／GO 共 4 秒，每張圖片仍為 1.2 秒、間隔 0.3 秒。

所有尺寸均確認：倒數與圖片中心一致、五張圖片切換時中心與展示區高度穩定、頁面沒有水平溢出、上下左右對齊保持、主面板頂部不因開始而移動、沒有 JavaScript 執行錯誤。
