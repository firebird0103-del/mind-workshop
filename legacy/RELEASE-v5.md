# v5 多彩生活物件測試版｜2026-10-02

這一版落地的是已認可的多彩生活物件風格，重點為找錯與工作記憶，不宣稱四款遊戲已全部完成新一輪 UI 重製。

## 開啟方式

完整解壓縮，保持整個資料夾結構，使用瀏覽器開啟 index.html。不需安裝或連網。
不要只複製 HTML；assets、JS 和 CSS 也需要保留。

- index.html：遊戲大廳
- find_diff_game.html：上方資訊、下方雙圖的新版找錯
- memory_game_hard.html：生活物件版工作記憶
- art-gallery.html：80 件實際素材，含 48px 小尺寸預覽
- assets/ARTWORK.md：素材清單、製作方式與完整生成提示詞

## 本次變更

1. 移除找錯與記憶關的抽象圖庫及舊 emoji 題目池，使用 80 件可辨識的具名物件。
2. 同一盤面不重複；替換物件不能與該題基準圖重複。跨題優先用尚未出現的素材。
3. 找錯改為上方橫式資訊列、下方雙圖；棋盤依可用寬高計算大小。短螢幕保留點選尺寸並容許捲動，不硬塞縮小。
4. 640px 以下雙圖改上下排列；高密度設定若超過手機寬度，盤面可橫向捲動，保留 44px 點選格。
5. 左圖只供參照，右圖使用原生按鈕，支援點擊、觸控與 Enter / 空白鍵。找到後鎖定，不重複計分。
6. 找錯 HUD 顯示「本題分數」，點錯立即反映扣分；結束才顯示平均分數，避免原先累計分數和標示混淆。
7. 工作記憶揭示正確答案時顯示圖片與中文名稱，不再出現 [object Object]。
8. 記憶選項防重複選取，送出後不可修改或重複計分。長序列部分答對分數不超過「全選對但順序錯」的 80 分。
9. 圖片先載入完成再開始；失敗會顯示提示並可重試，避免記憶圖片空白卻開始倒數。
10. 保留「空間認知」名稱、時鐘直接拖針操作、原有四格 logo，以及語意判斷的玩法。
11. 找錯換題只用短淡入；啟用「減少動態效果」時停用。記憶圖形動畫也尊重該設定。
12. 找錯與記憶允許使用瀏覽器縮放。

圖庫是 80 件，不是無限素材。預設找錯 3 題共使用 86 個物件位置，因此第 3 題會有 6 個跨題重用；同一盤面內仍不重複。

## 已檢查

- Node.js 語法：所有 JS、HTML 內嵌腳本。
- 本地 HTML 的 CSS / JS / HTML / PNG 路徑存在。
- 144 組找錯測試，共 432 題：3～8 格邊長、1～8 個不同處；盤面唯一性、替換數、扣分、完成流程、防重複計分、最終成績。
- 記憶長度 3 / 5 / 6 / 8：倒數與展示流程、唯一選項、取消重排、送出鎖定、答案揭示、正確／部分／錯誤計分。

- 80 件素材皆有圖像內容，兩兩比較 3160 組，未發現相同或近乎相同的像素圖。
- 已逐張查看四張原始圖集，並修正原本平均分格會碰到圖案邊缘的顯示視窗。
- 飛機與火車在原圖分隔處的留白较窄，遊戲容器另保留外邊距；仍請在素材總覽確認實際顯示。

以上遊戲測試使用 DOM 替身與模擬計時器，不是瀏覽器實測；像素差異檢查也不等於使用者辨識度研究。

## 尚需實機確認

目前環境無法完成瀏覽器自動化驗收，以下項目未宣稱通過：

- 全螢幕 1920×1080、1366×768，以及你現場使用的螢幕與縮放比例。
- 雙圖是否同時完整出現、說明文字換行是否合適、下一題按鈕是否方便點選。
- 直向手機、橫向平板、最大 8×8 設定的捲動與可讀性。
- PNG 在離線 file:// 頁面的 SVG 視窗是否正常顯示，以及觸控、鍵盤與螢幕閱讀器。
- 7 歲兒童與長者能否在 48px 預覽直接認出每個物件；辨識不清的單件應替換，不以改名掩蓋。
