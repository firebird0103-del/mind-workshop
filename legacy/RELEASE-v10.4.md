# v10.4｜關卡對齊與進度修正

## 變更

各關的上方功能列與下方主面板現在使用同一個左右邊界，並隨螢幕可用寬度縮放。

- 第一關最大 1180px、第二關最大 1920px、第三關最大 1480px、第四關最大 1120px，沿用各關原有主面板最大寬度。
- 品牌靠左、音效靠右，「回大廳」以面板的幾何中心置中；功能列與面板間距統一為 12px。
- 600px 以下，品牌與操作按鈕分成兩列；「回大廳」仍置中，音效靠右，避免與品牌互相擠壓。
- 同一關切換準備、遊玩或結果階段，主面板的寬度及文件內頂部位置維持一致；高度依內容調整。
- 第二關資訊列與外框同寬；原有圖格仍依可用空間縮放，題目測量值不再影響外層功能列寬度。
- 第四關準備畫面讀取實際 `totalRounds`，預設顯示 `0 / 10`，並支援自訂題數。第一題開始後仍依原有規則顯示 `1 / 10`。

新增 `brain-game-frame.css` 統一管理外框，由四關 HTML 在既有樣式之後引入。第四關另增加一次準備狀態初始化；題目產生、判分、音效、遊玩節奏及其他遊戲 JavaScript 檔案保持原樣。v10.3 入口及其標題圖稿未修改。

## 驗證

使用 Microsoft Edge 155（Chromium），直接以 `file://` 開啟本地檔案：

- 四關各 10 種視窗尺寸，共 40 組檢查：1920×1080、1440×900、1366×768、1024×768、768×1024、601×800、600×800、390×844、320×740、844×390。
- 每組確認：上下左右邊界一致、「回大廳」置中、功能列元件互不重疊、頁面沒有水平溢出。
- 桌面／手機：第三關記憶、答題與回饋階段；第二關三題與結果；第一關進入遊玩；第四關十題與結果，確認外框寬度與文件內頂部位置穩定。內部內容可正常捲動。
- 第四關預設準備進度 `0 / 10`，逐題進度直到第十題並完成；另以獨立測試瀏覽器儲存自訂七題，重載後顯示 `0 / 7`，開始後 `1 / 7`。
- 本輪未啟動 Electron，也未驗證完整第一關／第三關的所有回合。

實際截圖與檢查數據位於 `preview/v10.4/`。其他 preview 子目錄為歷史紀錄。
