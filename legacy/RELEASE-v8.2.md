# v8.2：元件重製，待視覺驗收

不是新生成示意圖。本次修改入口的實際 HTML、CSS 和 SVG 元件；保持 71vw／1360px 上限留白。

## 修訂

- 雲雲使用現有 PNG，不再次生成角色。改由 inline SVG 在顯示時濾除低透明度暈影，依不透明輪廓生成白邊及獨立落影。110px 寬顯示下新增白邊約 3.4px，避免大圖內白邊縮小後消失。圖像本身未改；SVG filter 會影響顯示邊緣。
- 四卡以獨立 SVG 曲線做紙張輪廓、色面、淡高光、落影與真正沿外輪廓連接的折角，不再依賴矩形框與三角形覆蓋。各卡漸層 ID 獨立，邊線不隨卡片縮放變粗。
- 膠帶分離內容與背景層，增加細透光線與不規則撕邊。
- 主卡文字 32px／說明 20px（較窄桌面 28px／18px），插圖適度增大，保留全卡點選與鍵盤操作。
- 其餘頁面、形色 10 題、計分、音效、紀錄、素材圖集都未改。

## 驗證與限制

已執行 game-logic、v6-layout-names、v7、v8、v8.2 程式測試；新增四卡獨立 SVG、漸層 ID、貼紙濾鏡引用檢查。

本版未完成實際瀏覽器視覺驗收；既有本機頁面工具存取限制未繞過。測試通過不代表畫面與示意圖相同，也不代表無捲動、實體觸控與所有 SVG filter 行為已驗證。請使用現代 Edge／Chrome，開啟 index.html 核對：雲雲輪廓白邊與陰影、折角連接、紙卡輪廓、標題不碰插圖、鍵盤焦點、縮放後版面。

若無法顯示 SVG 貼紙濾鏡或紙卡背景，請回報瀏覽器版本與截圖。本版保留為獨立資料夾，v8／v8.1 不覆蓋。
