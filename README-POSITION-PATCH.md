# Fix3 語意判斷定位修補

準備畫面的開始按鈕原本會參與垂直置中；開始後隱藏按鈕，且規則文字高度改變，使同一位移設定套在不同基準位置。

本修補將規則、選項與按鈕分配到固定的三列，預留文字與按鈕空間。同一視窗與設定下，準備及遊玩共用選項列的尺寸與位置計算，不再使用當下按鈕／規則框高度計算卡片大小。工具的準備文字也改為直接取正式模板。

將壓縮包下列三檔覆蓋至 Fix3 網站根目錄（若倉庫以 dist 發布，放入 dist），再按 Ctrl＋F5：

- native-games/layout.js
- native-games/workbench-theme.css
- workbench-layout-editor.html

本包不包含 workbench-layout-settings.js，你自行調好的設定不會被覆蓋。更新後使用新版 HTML 工具；仍以相同模擬視窗尺寸比較。此修補統一狀態切換的基準，不會讓不同視窗尺寸的相對位移變成相同絕對座標。

遊戲規則、計分、題庫、計時、3D 模型與其他關卡行為均保留。121 項自動化測試通過，包含直接運行布局觀察器，模擬開始按鈕消失、規則高度改變後比對選項列位置與尺寸；本次未進行實際瀏覽器視覺複驗。
